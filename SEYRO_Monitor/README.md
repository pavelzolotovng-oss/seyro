# SEYRO Monitor

Нативное Android-приложение для чтения метрик IN/OUT-узлов SEYRO из уже существующего FastAPI. Мониторинг использует только `GET /api/v1/monitor/nodes`; отправки данных и управляющих запросов нет.

## Сборка

Откройте `SEYRO_Monitor/` в Android Studio (JDK 17, Android SDK 35) и соберите вариант `release`. Для обновления установленного APK должны быть настроены те же секреты подписи, что и у предыдущих сборок Monitor: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

GitHub Actions собирает и публикует подписанный APK из `main` при изменениях в этой папке. Первое имя версии — `0.1`; номер сборки монотонно растёт для установки обновлений поверх предыдущей версии. Релиз Monitor имеет собственный префикс тега и не влияет на релизы VPN.

## Данные

Каждые 15 секунд приложение загружает все узлы, включая свёрнутые карточки, и обзор с числом онлайн-пользователей. `metrics.samples` сливаются по `sampled_at`; последние 30 минут хранятся только в памяти процесса. Опрос останавливается в фоне. Настройки адреса API и Monitor Bearer-токена сохраняются локально; токен используется только в заголовке `Authorization` для GET-запросов. В настройках можно очистить локальную историю графиков; серверные данные это не меняет.
