# SEYRO Monitor

Нативное Android-приложение на Kotlin и Jetpack Compose для **только чтения** операционных данных SEYRO через существующий FastAPI. Оно не содержит SSH-клиента, VPN-runtime и функций изменения серверов.

## Подключение к API

В разделе «Настройки» указан сервер `https://admin.seyro.ru`. Вставьте выпущенный `monitor-token` и нажмите «Сохранить и подключиться». Токен шифруется ключом Android Keystore и хранится на устройстве. В приложении выполняются только GET-запросы с заголовком `Authorization: Bearer …`; управление серверами отсутствует. В этом разделе также отображаются версия и номер сборки приложения.

Используются действующие read-only маршруты FastAPI:

```text
GET /api/v1/monitor/overview
GET /api/v1/monitor/nodes
GET /api/v1/monitor/system/status
```

Обзор показывает сводку по узлам, статусы IN/OUT, Xray, синхронизацию и число онлайн-пользователей. Для каждого узла приложение читает `metrics` из списка и detail-маршрута: `cpu_percent`, `ram_used_bytes`, `ram_total_bytes`, `disk_used_bytes`, `disk_total_bytes`, `network_rx_bytes_per_sec`, `network_tx_bytes_per_sec`, `uptime_seconds`, `sampled_at`. Устаревшие показатели отмечаются по `metrics_stale`; пользовательский онлайн-счётчик — по `online_users_stale` и времени `online_users_sampled_at`.

Обзор обновляется каждые 15 секунд, пока приложение открыто. На любом экране приложение также опрашивает список узлов и записывает замеры всех серверов, даже если их карточки не открывались. При отсутствии второго замера CPU и скорости сети показываются как ожидающие данных.

В подробностях узла приложение строит графики CPU, RAM/диска и сетевой скорости по секундным точкам из `metrics.samples`. Подписи по нижней оси показывают время замеров (UTC). Приложение хранит до 900 точек на узел (примерно 15 минут) и собирает их для всех узлов, пока оно открыто. Локальная история очищается при перезапуске приложения.

## Обновления из GitHub

При запуске приложение проверяет GitHub Releases не чаще одного раза в 6 часов; в разделе «Настройки» проверку можно запустить вручную. Проверяется только релиз с тегом `seyro-monitor-vX.Y.Z` и APK `seyro-monitor.apk`. При наличии новой версии приложение показывает заметки релиза, скачивает APK, сверяет SHA-256 и передаёт установку системному Android Package Installer. Если read-only токен сохранён, форма ввода скрыта; удалить токен и вернуться к настройке подключения можно кнопкой «Удалить ключ».

Релизы выпускаются тегом `seyro-monitor-vX.Y.Z`. Для этого в GitHub Actions необходимы четыре Secrets: `SEYRO_MONITOR_KEYSTORE_BASE64`, `SEYRO_MONITOR_KEYSTORE_PASSWORD`, `SEYRO_MONITOR_KEY_ALIAS` и `SEYRO_MONITOR_KEY_PASSWORD`. Это должен быть один постоянный ключ подписи: Android отклонит обновление, если APK подписан другим ключом.

## Сборка

Откройте каталог `SEYRO_Monitor` в Android Studio и соберите debug APK. Требуются JDK 17, Android SDK 35 и доступ Gradle к Google/Maven Central. GitHub Actions также собирает debug APK при изменениях в этом каталоге.
