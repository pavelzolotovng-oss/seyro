# SEYRO Monitor

Отдельный Android-проект для мониторинга серверов SEYRO. Не меняет код VPN-клиента SEYRO Lite.

## Текущий этап
- Тёмный интерфейс и карточки IN, OUT Helsinki, OUT Frankfurt.
- Android-проект на Java, Application ID: `ru.seyro.monitor`.
- Подготовлена зависимость SSH-библиотеки для следующего этапа.

## Что ещё не реализовано
Карточки пока демонстрационные: реальные SSH-подключения, показатели CPU/RAM/диска, статус служб, история событий и уведомления ещё предстоит добавить.

## Безопасность SSH
До подключения реальных серверов необходимо реализовать проверку host key (known_hosts или закреплённый отпечаток). Не отключать проверку подлинности сервера, не записывать приватные ключи и секреты в логи. Предпочтительно использовать отдельный ключ мониторинга и непривилегированного пользователя с минимальными правами.

## Сборка
Workflow GitHub Actions собирает debug APK и публикует его как artifact при изменении каталога `SEYRO_Monitor/`.
